# Evaluating-the-Generalization-of-Machine-Learning-Models-for-Network-Intrusion-Detection-
Evaluating the Generalization of Machine-Learning Models for Network Intrusion Detection on the CICIDS2017 Dataset
• Investigated the performance of machine-learning models for Network Intrusion Detection using the CICIDS2017 dataset.
• Analyzed a class-capped dataset containing 123,901 network flows and 77 numerical features.
• Compared Logistic Regression, Random Forest, and LightGBM using stratified 5-fold cross-validation, daybased evaluation, and leave-one-attack-family-out testing.
• Examined the influence of the Destination Port feature on model performance through feature-removal experiments.
• Observed substantial differences between conventional cross-validation and day-based evaluation, highlighting
the importance of realistic model testing.
• Tools: Python, Pandas, Scikit-learn, LightGBM, Google Colab.
